# Publicações — Codex Guide

This folder is a separate Git repository used for public static pages deployed by Cloudflare Pages.

## Important

- Run `git status --short` inside this folder when checking changes here.
- Public pages usually live at `repositorio-publicacoes/{slug}/index.html`.
- Root repo changes and public repo changes must be reported separately.

## Static Page Work

- Prefer single-folder pages with local assets.
- Keep links robust when files may be viewed from the public repo alone.
- Use `index.html` as the entry point.
- For visual edits, run a local static server and inspect the page in a browser.
