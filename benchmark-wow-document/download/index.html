Como usar em 3 minutos

O arquivo é uma base de contexto. A pergunta faz a diferença.

Codex

Coloque o .md no workspace e peça: “Leia este documento, preserve as fontes e crie uma matriz de conteúdos para a promessa da mentoria.”

Claude Code

Adicione o arquivo ao projeto ou à conversa e peça uma síntese por nível de consciência, separando evidência de hipótese.

Gemini

Faça upload do .md e solicite uma leitura crítica com links de referência, sem inventar métricas ou promessas.

Prompt-base: “Use o Wow Document como contexto. Trabalhe somente com conteúdos ligados à promessa das mentorias. Separe fatos observados, inferências e recomendações. Cite o link de origem quando usar um criativo. Agora, [escreva sua tarefa].”
