# Tutorial rápido — Wow Document de benchmark

## 1. O que você recebeu

O `wow-document-harmonizacao-facial.md` é um arquivo de contexto. Ele reúne a leitura do mercado de mentorias em harmonização facial, padrões de promessa, níveis de consciência, transcrições e links de referência.

Use o documento para orientar decisões. Não trate visualizações, cópias de anúncios ou engajamento como prova de faturamento: são sinais de mercado, não garantia de performance.

## 2. Como usar no Codex

1. Coloque o arquivo dentro do workspace/projeto.
2. Peça para a IA ler o documento antes de executar a tarefa.
3. Diga para manter separados fatos observados, inferências e recomendações.

Prompt inicial:

> Leia `wow-document-harmonizacao-facial.md` como contexto. Trabalhe somente com conteúdos ligados à promessa das mentorias. Cite os links de origem quando usar um criativo. Separe fatos, inferências e recomendações. Agora crie uma matriz de 20 ideias de Reels para [minha mentoria].

## 3. Como usar no Claude Code

Adicione o `.md` à pasta do projeto ou anexe o arquivo na conversa. Em seguida, peça uma tarefa específica: calendário editorial, análise de oferta, roteiro, página de captura ou variações de anúncio.

Prompt sugerido:

> Use o Wow Document como base de pesquisa. Não copie os concorrentes. Extraia padrões de mecanismo, prova, objeção e CTA para propor uma comunicação original para [público/oferta]. Marque toda hipótese como hipótese e preserve as referências.

## 4. Como usar no Gemini

Faça upload do arquivo e informe o resultado desejado. Se precisar analisar um vídeo ou frame, use o link de referência registrado no documento e peça uma análise específica daquele material.

Prompt sugerido:

> Analise este benchmark por nível de consciência do público. Para cada nível, indique promessa, objeções, formato de conteúdo e CTA mais adequado. Não invente dados ausentes; sinalize lacunas.

## 5. Como usar em qualquer IA

O fluxo é sempre o mesmo:

1. Anexe ou cole o documento.
2. Explique qual é sua oferta e ICP.
3. Restrinja o escopo à promessa da mentoria.
4. Peça a saída em uma estrutura clara.
5. Solicite as fontes usadas e revise alegações antes de publicar.

Prompt universal:

> Leia o documento anexado. Meu produto é [produto], para [ICP], com a promessa [promessa]. Use apenas os aprendizados relacionados à mentoria. Gere [entrega]. Organize por nível de consciência. Diferencie dado observado de interpretação e cite as referências.

## 6. Regra editorial deste material

O recorte foi feito para conteúdos ligados a formação, técnica, carreira, gestão, captação, conversão e operação de mentoria. Conteúdos de vida pessoal e lifestyle não entram como base para a estratégia da promessa.
