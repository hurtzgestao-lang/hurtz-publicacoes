# Link bio Marcos

Formulario comercial aberto para empresarios que chegam pelo link da bio do Marcos.

## Estrutura

- `index.html` - entrada estatica.
- `styles.css` - layout compacto seguindo Off-white, Carvao, Brasa e Inter.
- `app.js` - perguntas, validacao, tracking de origem e envio para WhatsApp.
- `assets/logo-atual-escuro.png` - logo oficial para fundo escuro.
- `assets/logo-atual-icone-escuro.png` - favicon.

## Perguntas

1. Qual o seu nome?
2. Qual seu e-mail?
3. Qual seu telefone?
4. Qual o seu cargo?
5. Qual seu segmento?
6. Qual seu faturamento?
